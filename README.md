# CampusConnect – Campus Event Calendar

CampusConnect is a responsive, frontend-only website designed to help students discover, explore, and manage campus events and activities in one place.

## Features
- Browse upcoming campus events.
- Search events by name or keyword.
- Filter events by category.
- Add custom campus events.
- Save favourite events.
- Delete custom events.
- View event details and event counts.
- Save event data and favourites using browser LocalStorage.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- LocalStorage

## How to Run
1. Download or clone the project repository.
2. Open the `campusconnect` folder.
3. Open `index.html` in a web browser.
4. Alternatively, use the VS Code Live Server extension.

## Deployment
CampusConnect can be deployed independently using Vercel.

- Framework Preset: Other
- Build Command: Leave blank
- Output Directory: `.`

## Project Type
Frontend-only web application. No backend or database is required. Custom events and favourites are stored locally in the user's browser.
